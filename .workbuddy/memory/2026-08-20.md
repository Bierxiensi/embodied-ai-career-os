### 关键发现
1. **现有项目技术栈**：Next.js 16 App Router、React 19、Tailwind v4（CSS-first 配置 @theme）、
   零第三方 UI 库（CareerCard/TaskCard/AgentActivity 等全部手写）、零图表库（雷达图纯 SVG）。
   字体 Geist，Server Component 拉数据 + `router.refresh()` 模式。
2. **命名规范**：组件 PascalCase.tsx 单文件单默认导出；`type Props = {...}` 内联；
   常量 UPPER_SNAKE_CASE；服务层 camelCase；后端 snake_case→camelCase 转换。
3. **Ardot SVG 解析器限制（重要）**：反复报 "degenerate geometry" 错误，
   **根因是纯水平/纯垂直直线（M180 180L180 40 之类）的包围盒退化为 0×N 或 N×0**。
   修复：给所有水平/垂直线段加 1px 偏移（如 M180 180L181 40），使包围盒非零。
   已应用于雷达图的两根垂直轴线。
4. **风格映射**：Apple 模板的 Action Blue #0066CC 用作主操作色；
   保留项目语义色 emerald（成功/当前）、amber（待办）、red（最大缺口）；
   6 个 Agent 色条与项目 AGENT_COLORS 一致（planner=sky, reviewer=violet, career=amber,
   research=rose, supervisor=zinc）。
