# 北京在职博士 · 易录取好毕业版本

> **整理日期**：2026-08-24  
> **筛选标准**：好录取、好毕业、能学东西（不追求学校档次）  
> **个人背景**：北航研三非全日制硕士，Agent 应用开发背景，目标具身智能/VLA 方向

---

## 核心结论

985/211 的在职博士竞争大、门槛高，**市属院校和行业特色院校才是性价比最优解**。

| 维度 | 985/顶尖 | 211/行业特色 | 市属/普通 |
|------|---------|-------------|----------|
| 录取率 | <10% | 20-40% | 40%+ |
| 论文要求 | 2篇SCI硬核 | 1篇核心或专利可替 | 不强制核心论文 |
| 英语门槛 | CET-6≥450 | CET-6≥425 | CET-4≥425 或校内补考 |
| 工作经验 | 3-5年 | 部分要求3年 | 多数无硬性要求 |

## 一、优先推荐（好录取 + 能学东西）

### 1. 北京邮电大学 — 电子信息非全日制博士 ⭐⭐⭐⭐⭐

| 项目 | 详情 |
|------|------|
| **专业** | 085400 电子信息（非全日制）|
| **相关方向** | 智能机器人、控制理论与控制工程、模式识别与智能系统、智能检测与控制 |
| **招生院系** | 人工智能学院 / 现代邮政学院（自动化学院）|
| **学制** | 4年（最长6年）|
| **学费** | 3万元/年（总计12万）|
| **报名时间** | 2026.04.30–05.15（春季第二批）|
| **报名方式** | 申请-考核制（材料审核+面试，无统考笔试）|
| **英语要求** | CET-6≥425 或 CET-4≥485（专业学位非应届可适当放宽）|
| **论文要求** | 无硬性SCI要求 |
| **工作年限** | 招生简章**未明确要求硕士毕业后工作年限** |
| **关键优势** | 1. AI学院有**智能机器人**研究方向 2. 不要求核心期刊论文 3. 申请-考核制，免统考 4. 北航硕背景有优势 |
| **链接** | [北邮2026博士简章](https://zsc.bupt.edu.cn/info/1016/1254.htm) |

**适配度判断**：这是目前**最匹配你需求**的选项。电子信息专业覆盖机器人/AI/控制方向，北航硕士背景在申请时是加分项。

### 2. 中国石油大学（北京）— 非全日制工程博士 ⭐⭐⭐⭐

| 项目 | 详情 |
|------|------|
| **专业** | 工程类专业学位（非全日制）|
| **相关方向** | 机械（含机器人）、人工智能、自动化控制 |
| **学制** | 4年 |
| **学费** | 1.5万元/年（与全日制持平，**行业最低价**）|
| **报名时间** | 全年常态化报名+终期补录批次 |
| **报名方式** | 申请-考核制 |
| **英语要求** | **CET-4≥425即可**（非全日制专属降分），无证书可参加校内补考（卷面40分即可进复试）|
| **论文要求** | 不强制核心期刊 |
| **关键优势** | 1. 学费最低（1.5万/年）2. 英语门槛全网最低 3. 校内补考通道兜底 4. 全年可报名 5. 竞争小（能源类院校，理工科报考热度低）|
| **链接** | [中石大在职博士解读](https://m.toutiao.com/article/7653676796370371124) |

**适配度判断**：如果你是**冲着"好考好毕业"**，这是北京地区门槛最低的 211 院校。缺点是机器人方向不是传统强项，但"能学东西"方面——申请-考核制导师主导，你可以找做自动化/智能控制方向的导师。
