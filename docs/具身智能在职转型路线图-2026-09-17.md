## 二、三阶段路线图

### 阶段 1：拿到入口 offer（0-2 个月，2026-09 → 2026-11）

**目标**：拿到具身数据工程师 offer，进入具身公司。

**投递清单**（按优先级）：
1. **优必选 J18688 具身数据工程师**（深圳，校招 8/19 已开，9-11 月笔面试）—— 优先级最高
2. **千觉机器人 具身数据基础设施工程师**（上海，20K+，本科可投）
3. **广州凡拓 具身数据系统工程师**（广州，20-40K，ROS2 加分）
4. **北京物智 具身智能大模型数据算法工程师**（北京，2 年经验要求，你符合）
5. **银河通用 09-22 北航沙河宣讲会**（J5-101 教室，18:30）—— 直接接触机会
6. **美团 LongCat 实习**（VLA/World Model 方向，实习转正）

**简历叙事重构**（关键）：
- 把"标书审核 Agent"重写为"**非结构化数据引擎**"：抽取/结构化/质量校验/回流，3000+ 份，覆盖率 56%→90%
- 突出 RAG 多模态文档召回 85%（直接对应具身数据岗的多模态处理）
- SO101 真机闭环作为"具身诚意证明"：遥操作 + 20 episodes + ACT 训练
- 时序预测科研作为"序列建模能力"背书

**面试前突击**（1-2 周）：
- MCAP / LeRobot 数据格式（读官方文档 + 跑一次 demo）
- 坐标系变换 / 时间戳同步（理论基础 + ROS2 tf2 实操）
- Open X-Embodiment 数据集（了解格式与规模）

### 阶段 2：在职补课 + SO101 进阶（2-6 个月，2026-11 → 2027-03）

**目标**：在具身公司内积累算法向迁移的证据。

**在职学习路线**（按方向）：

| 方向 | 资源 | 产出证据 |
|------|------|---------|
| VLM 基础 | ViT / CLIP / LLaVA 论文精读 + 一次 LLaVA LoRA 微调（用 SO101 数据） | 可陈述的 VLM 微调经验 |
| 模仿学习进阶 | Diffusion Policy 论文 + SO101 上跑通 | 泛化成功率提升数据 |
| 世界模型 | Dreamer V3 / JEPA 论文精读 | 用你的时序预测背景做差异化叙事 |
| 机器人数据深度 | 在职项目实战（公司真实数据） | 端到端数据管线落地经验 |

**关键**：在职期间尽量争取接触算法团队的真实数据与训练流程，这是脱产学习得不到的。

### 阶段 3：内部转岗或跳槽算法岗（6-12 个月，2027-03 → 2027-09）

**目标**：从数据工程师转为算法工程师。

**路径 A（优先）：内部转岗**
- 成本低、信任度高、不需重新面试
- 前提：阶段 2 在职期间主动承接算法团队的工程任务，建立信任

**路径 B（备选）：跳槽**
- 已具备"具身公司工作经验 + VLM 微调 + SO101 进阶"证据
- 可投 VLA 算法岗 / 世界模型研究岗
- 此时你的画像已从"LLM 应用工程师"变为"具身数据工程师 + VLM 实操"
